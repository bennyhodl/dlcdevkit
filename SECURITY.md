# Security Policy

To report security issues, either

- send an email to `ben AT bitcoinbay DOT foundation` (not for support), or
- open a security advisory on GitHub at
[`https://github.com/bennyhodl/dlcdevkit/security/advisories`](https://github.com/bennyhodl/dlcdevkit/security/advisories).

The following key may be used to communicate sensitive information to DLC Dev Kit via email:

| Name | Fingerprint |
| ---- | ----------- |
| `ben@bitcoinbay.foundation` | `5D34 2974 4CB5 F205 76ED A743 B518 AFC2 A836 3DD9` |

You can import the key by running the following command:
```
gpg --recv-keys 5D3429744CB5F20576EDA743B518AFC2A8363DD9 --keyserver hkps://keys.openpgp.org
```

You can also download it from [GitHub](https://github.com/bennyhodl.gpg):
```
curl -sSL https://github.com/bennyhodl.gpg | gpg --import
```
